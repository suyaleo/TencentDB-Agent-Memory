# Product brief

## Objective
Deploy TencentDB Agent Memory on the Ubuntu execution host as a shared external memory, knowledge, and reviewed-skill plane for Hermes, Codex CLI, Grok CLI, and agy CLI.

## Acceptance boundary
- Preserve each agent's native inference/OAuth path.
- Provide shared recall, search, capture, session flush, and skill tools through MCP.
- Keep private/team/agent ACLs explicit in Memory Hub.
- Keep ports local by default and secrets outside Git.
- Validate cross-agent retrieval with real running services.

This is external inference-time memory, not model-weight training.
